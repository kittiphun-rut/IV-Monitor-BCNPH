  คู่มือการปฏิบัติงาน

  การใช้งานระบบเฝ้าระวัง
  การให้สารน้ำทางหลอดเลือดดำ
  “Smart IV Alert”
  สำหรับพยาบาลวิชาชีพ
  หอผู้ป่วยอายุรกรรม
  โรงพยาบาลสูงเม่น อำเภอสูงเม่น จังหวัดแพร่
  จัดทำโดย
  นายกิตติพันธ์ รัตนคร
  นักวิชาการคอมพิวเตอร์
  มหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย วิทยาเขตแพร่
  ภายใต้โครงการวิจัย
  ผลของการใช้นวัตกรรม Smart IV Alert
  ต่อความแม่นยำในการแจ้งเตือนและปริมาณสารน้ำที่ผู้ป่วยได้รับ
  วิทยาลัยพยาบาลบรมราชชนนี แพร่
  คณะพยาบาลศาสตร์ สถาบันพระบรมราชชนก
  ฉบับปรับปรุงครั้งที่ ๑  พุทธศักราช ๒๕๖๙
  ใช้กับเฟิร์มแวร์เครื่องประจำเตียงรุ่น 7.7.2
  และเครื่องศูนย์กลางรุ่น 4.7.4-OLED


==============================================================================
  คำนำ
==============================================================================

  การให้สารน้ำทางหลอดเลือดดำเป็นหัตถการที่พบบ่อยที่สุดอย่างหนึ่งในหอผู้ป่วยอายุรกรรม
  ความคลาดเคลื่อนของอัตราการไหลเพียงเล็กน้อยที่สะสมตลอดเวรอาจทำให้ผู้ป่วยได้รับสารน้ำ
  มากหรือน้อยกว่าแผนการรักษาอย่างมีนัยสำคัญ ในขณะที่พยาบาลหนึ่งคนต้องดูแลผู้ป่วยหลาย
  เตียงพร้อมกัน การเดินไปนับหยดที่กระเปาะทีละเตียงจึงทำได้ไม่ถี่เท่าที่ควร
  ระบบ Smart IV Alert พัฒนาขึ้นเพื่อเป็น “ผู้ช่วยเฝ้าระวัง” ที่ทำงานแทนการนับหยดด้วยตา
  ตลอดเวลา โดยติดตั้งเครื่องตรวจวัดขนาดเล็กไว้ที่กระเปาะหยดของแต่ละเตียง ส่งข้อมูล
  มายังเครื่องศูนย์กลางที่เคาน์เตอร์พยาบาล และแจ้งเตือนทันทีเมื่อการไหลผิดไปจากแผน
  หยุดไหล หรือสารน้ำใกล้หมด
  คู่มือฉบับนี้จัดทำขึ้นเพื่อให้พยาบาลวิชาชีพที่ปฏิบัติงานในหอผู้ป่วยสามารถใช้งานระบบได้
  อย่างถูกต้อง ปลอดภัย และเป็นมาตรฐานเดียวกันทุกเวร เนื้อหาครอบคลุมตั้งแต่ความรู้พื้นฐาน
  เกี่ยวกับระบบ ขั้นตอนการปฏิบัติงานตามลำดับ ความหมายของสัญญาณเตือนทุกชนิดพร้อมแนว
  ทางการตอบสนอง การแก้ไขปัญหาที่พบบ่อย ไปจนถึงการบำรุงรักษาเบื้องต้น พร้อมทั้งแบบฟอร์ม
  สำหรับใช้งานจริงในภาคผนวก
  ผู้จัดทำขอขอบคุณคณาจารย์วิทยาลัยพยาบาลบรมราชชนนี แพร่ และทีมพยาบาลหอผู้ป่วยอายุรกรรม
  โรงพยาบาลสูงเม่น ที่ให้ข้อเสนอแนะอันเป็นประโยชน์ยิ่งต่อการออกแบบระบบและคู่มือฉบับนี้
  หากมีข้อผิดพลาดประการใด ผู้จัดทำยินดีรับฟังเพื่อปรับปรุงในฉบับต่อไป
  นายกิตติพันธ์ รัตนคร
  ผู้จัดทำ

๑.๑ ความเป็นมาและความสำคัญ
--------------------------------

  การให้สารน้ำทางหลอดเลือดดำโดยใช้ชุดให้สารน้ำแบบหยด (gravity drip set) อาศัย
  แรงโน้มถ่วงเป็นแรงขับเคลื่อน อัตราการไหลจึงเปลี่ยนแปลงได้ตลอดเวลาจากหลายปัจจัย
  เช่น ท่าทางของผู้ป่วย ความสูงของถุงสารน้ำ อุณหภูมิห้อง การพับของสาย และการคลายตัวของโรล
  เลอร์ การตั้งอัตราหยดเพียงครั้งเดียวเมื่อเริ่มให้สารน้ำจึงไม่อาจรับประกันได้ว่า ผู้ป่วย
  จะได้รับสารน้ำตรงตามแผนการรักษาตลอดช่วงเวลาที่กำหนด
  ในทางปฏิบัติ พยาบาลหนึ่งคนต้องรับผิดชอบผู้ป่วยหลายเตียงพร้อมกัน การเดินไปนับหยดที่
  กระเปาะของทุกเตียง ในทุกชั่วโมงจึงทำได้ยาก ความคลาดเคลื่อนของอัตราการไหลที่เกิดขึ้น
  ระหว่างรอบการตรวจเยี่ยมอาจไม่ถูกตรวจพบ จนกระทั่งสารน้ำหมดถุงหรือผู้ป่วยแสดงอาการ
  ระบบ Smart IV Alert จึงถูกพัฒนาขึ้นเพื่อทำหน้าที่เฝ้าระวังแทนสายตาของพยาบาลอย่าง
  ต่อเนื่องตลอดเวลา โดยใช้เซนเซอร์อินฟราเรดตรวจจับหยดสารน้ำที่ตกผ่านกระเปาะ คำนวณ
  อัตราการไหลตามเวลาจริง เปรียบเทียบกับแผนการรักษาที่พยาบาลตั้งไว้ และส่งสัญญาณ
  เตือนทันทีเมื่อพบความผิดปกติ

๑.๓ ขอบเขตของคู่มือ
-----------------------

  คู่มือฉบับนี้ครอบคลุมการใช้งานระบบ Smart IV Alert ในหอผู้ป่วยอายุรกรรม สำหรับผู้ป่วยผู้ใหญ่
  ที่ได้รับสารน้ำ ทางหลอดเลือดดำด้วยชุดให้สารน้ำแบบหยดอาศัยแรงโน้มถ่วง รองรับการเฝ้า
  ระวังพร้อมกันไม่เกิน ๘ เตียงต่อเครื่องศูนย์กลาง ๑ เครื่อง
  คู่มือฉบับนี้ไม่ครอบคลุมการใช้งานร่วมกับเครื่องควบคุมการให้สารน้ำอัตโนมัติ (infusion
  pump) การให้เลือดและส่วนประกอบของเลือด การให้สารน้ำในผู้ป่วยเด็กที่ใช้ชุดให้สารน้ำชนิด
  ๖๐ หยดต่อมิลลิลิตรในบริบทหอผู้ป่วยเด็ก และไม่ครอบคลุมการซ่อมบำรุงระดับอุปกรณ์
  อิเล็กทรอนิกส์ ซึ่งเป็นหน้าที่ของผู้ดูแลระบบ

๑.๔ ประโยชน์ที่คาดว่าจะได้รับ
--------------------------------

๑.๔.๑ ... ผู้ป่วยได้รับสารน้ำใกล้เคียงกับแผนการรักษามากขึ้น ลดภาวะได้รับสารน้ำเกินหรือขาด
๑.๔.๒ ................... ตรวจพบภาวะสายพับ เข็มเลื่อนหลุด และสารน้ำหมดถุงได้เร็วขึ้น
๑.๔.๓ .... ลดภาระการเดินตรวจนับหยดซ้ำ ๆ ทำให้พยาบาลมีเวลาให้การพยาบาลด้านอื่นมากขึ้น
๑.๔.๔ ... มีข้อมูลบันทึกรายนาทีสำหรับการส่งเวร การทบทวนคุณภาพ และการวิเคราะห์ผลการวิจัย

---------------------------------------------


+==========================================================================+
| ข้อควรระวังสำคัญ โปรดอ่านก่อนใช้งาน                                          |
| ๑.  ระบบนี้เป็นนวัตกรรมเพื่อการวิจัย ยังไม่ได้ขึ้นทะเบียนเป็นเครื่องมือแพทย์   |
| จึงใช้เป็น “เครื่องช่วยเฝ้าระวัง” เท่านั้น ไม่ใช้ทดแทนการประเมินและการตรวจเยี่ยม  |
| ผู้ป่วยตามมาตรฐานการพยาบาล                                                  |
| ๒.  ระบบไม่สามารถควบคุมหรือปรับอัตราการไหลได้ การปรับอัตราการไหลยังต้องทำที่  |
| โรลเลอร์ด้วยมือของพยาบาลเสมอ                                              |

| ภาวะหลอดเลือดดำอักเสบ (phlebitis) หรือการติดเชื้อที่ตำแหน่งแทงเข็มได้ พยาบาล |
| ต้องตรวจตำแหน่งแทงเข็มด้วยตาและการคลำตามรอบเวลาที่หอผู้ป่วยกำหนดเช่นเดิม         |
| ๔.  เมื่อระบบแจ้งเตือน พยาบาลต้องไปตรวจสอบที่เตียงผู้ป่วยด้วยตาเองทุกครั้ง ห้าม     |

| ๕.  หากระบบไม่แจ้งเตือน ไม่ได้หมายความว่าผู้ป่วยปลอดภัยเสมอไป การตรวจเยี่ยมตามรอบ |

| ๖.  ห้ามใช้ระบบนี้กับการให้เลือดและส่วนประกอบของเลือด สารน้ำที่มีความหนืดสูง     |
| หรือยาที่ต้องควบคุมอัตราอย่างเคร่งครัดด้วยเครื่องควบคุมการให้สารน้ำอัตโนมัติ       |

๒.๑ องค์ประกอบของระบบ
---------------------------

  ระบบ Smart IV Alert ประกอบด้วยส่วนหลักสามส่วนที่ทำงานร่วมกัน ดังนี้
(๑) ... เครื่องประจำเตียง (Station) ติดตั้งหนึ่งเครื่องต่อหนึ่งเตียง ทำหน้าที่นับหยดสารน้ำ คำนวณอัตราการไหล แสดงผลที่ข้างเตียง และส่งเสียงเตือนเฉพาะเตียงนั้น
(๒) ... เครื่องศูนย์กลาง (Host) ตั้งอยู่ที่เคาน์เตอร์พยาบาล รับข้อมูลจากเครื่องประจำเตียงทุกเครื่องทุกหนึ่งวินาที แสดงภาพรวมทุกเตียงบนจอเดียว และส่งเสียงเตือนรวม
(๓) ... หน้าเว็บสำหรับตั้งค่าและติดตามผล เปิดผ่านโทรศัพท์มือถือหรือแท็บเล็ตที่เชื่อมต่อสัญญาณ Wi-Fi ของเครื่องศูนย์กลาง ใช้กรอกแผนการให้สารน้ำ ดูกราฟย้อนหลัง และดาวน์โหลดข้อมูลสำหรับส่งเวร

[ภาพ]   ภาพที่ ๑  องค์ประกอบของระบบ

  เครื่องประจำเตียงและเครื่องศูนย์กลางสื่อสารกันโดยตรงด้วยคลื่นวิทยุระยะสั้น ไม่ต้อง
  อาศัยระบบเครือข่ายของโรงพยาบาลและไม่ต้องเชื่อมต่ออินเทอร์เน็ต ระบบจึงยังทำงานได้แม้
  ระบบเครือข่ายของโรงพยาบาลขัดข้อง

๒.๒ หลักการทำงานโดยสังเขป
-------------------------------

(๑) ... เซนเซอร์อินฟราเรดที่หนีบไว้กับกระเปาะหยดจะตรวจจับเงาของหยดสารน้ำที่ตกผ่านลำแสง
(๒) ... เครื่องประจำเตียงนับจำนวนหยด แล้วคำนวณอัตราการไหลเป็นมิลลิลิตรต่อชั่วโมงจากค่า Drop Factor ที่ตั้งไว้ ตามสมการที่ ฉ.๖ ในภาคผนวก ฉ
(๓) ... เครื่องประจำเตียงส่งข้อมูลให้เครื่องศูนย์กลางทุกหนึ่งวินาที และเครื่องศูนย์กลางส่งแผนการให้สารน้ำกลับมาให้เครื่องประจำเตียงเช่นกัน
(๔) ... เครื่องศูนย์กลางเปรียบเทียบอัตราการไหลจริงกับแผนการรักษา แล้วตัดสินใจแจ้งเตือนเพียงจุดเดียว จากนั้นสั่งให้เครื่องประจำเตียงที่เกี่ยวข้องแจ้งเตือนพร้อมกัน
  การตัดสินใจแจ้งเตือนรวมศูนย์ไว้ที่เครื่องศูนย์กลางเพียงจุดเดียว ทำให้ข้อความเตือนที่
  ข้างเตียง ที่เคาน์เตอร์พยาบาล และบนหน้าเว็บตรงกันเสมอ ไม่เกิดกรณีที่จอหนึ่งเตือนแต่
  อีกจอหนึ่งไม่เตือน

๒.๓ เครื่องประจำเตียงและการใช้ปุ่ม
------------------------------------

  การสั่งงานอาศัยจำนวนครั้งที่กดและระยะเวลาที่กดค้าง ตามตารางที่ ๒

  ๔.๕.๑ ขั้นที่ ๑  NOISE — วัดพื้นสัญญาณรบกวน (๓ วินาที)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  เมื่อไม่มีหยด” ค่านี้คือขีดล่างของฮาร์ดแวร์ ใช้เป็นฐานคำนวณเกณฑ์ในขั้นที่ ๓
(๑) ... ปิดโรลเลอร์ให้สนิท ห้ามให้มีหยดตกระหว่างสามวินาทีนี้ ถ้ามีหยดตกค่าที่วัดได้จะผิด
(๒) .................................... อยู่นิ่ง ๆ ไม่จับกระเปาะ ไม่ขยับเสาน้ำเกลือ
(๓) ............. อ่านค่า NOISE pp ที่แสดง ยิ่งต่ำยิ่งดี เมื่อขึ้น RESULT OK แสดงว่าผ่าน
(๔) ... ถ้าค่าสูงผิดปกติ ให้ตรวจแสงรบกวน การสั่นของเสา และความแน่นของหัวหนีบ แล้วทำใหม่

  ๔.๕.๒ ขั้นที่ ๒  DROPS — เรียนรู้จากหยดจริง
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  จอขึ้นข้อความ LET IT DRIP NOW เครื่องกำลังเก็บตัวอย่างหยดจริงเพื่อวัดว่า หยดหนึ่ง
  หยดทำให้สัญญาณเบนไปเท่าไรและนานเท่าไร
(๑) .................... เปิดโรลเลอร์ให้หยดตามปกติ ที่อัตราใกล้เคียงกับที่จะใช้จริง
(๒) ... เครื่องเก็บตัวอย่างจนครบ ๖ หยด หรือจบเร็วกว่านั้นถ้าได้ ๓ หยดแรกที่ความสูงใกล้เคียงกัน
(๓) ... ดูบรรทัด DROPS ว่าเดินขึ้นหรือไม่ ถ้าไม่เดินเลยแปลว่าเซนเซอร์ยังจับหยดไม่ได้ ให้กดปุ่มออกแล้วจัดตำแหน่งใหม่
(๔) ... ถ้าเก็บได้ไม่ถึง ๓ หยดภายใน ๑ นาที เครื่องจะขึ้น NOT ENOUGH DROPS และยกเลิกการคาลิเบรต

  ระหว่างขั้นนี้เครื่องจะหาทิศของสัญญาณเองด้วยว่าหยดทำให้ค่าลดลงหรือเพิ่มขึ้น พยาบาล
  ไม่ต้องตั้งค่าส่วนนี้

  สัญญาณรบกวนอย่างน้อย ๓ เท่า และต้องต่ำกว่าหยดที่จางที่สุดที่วัดได้พอสมควร แล้วบันทึกค่าลง
  หน่วยความจำถาวรทันที

(๕) ............ เมื่อพอใจแล้ว กดปุ่ม ๑ ครั้งเพื่อจบ ค่าที่ได้ถูกบันทึกไว้แล้วตั้งแต่ขั้นที่ ๓

(๑) ..... เปลี่ยนชุดให้สารน้ำ หรือเปลี่ยนยี่ห้อ เพราะขนาดหยดและความใสของกระเปาะต่างกัน
(๒) .......................... เปลี่ยนชนิดสารน้ำที่มีความหนืดต่างจากเดิมอย่างชัดเจน
(๓) ................... ถอดเซนเซอร์ออกแล้วนำกลับไปหนีบใหม่ หรือขยับตำแหน่งหัวหนีบ
(๔) ....................................... ย้ายผู้ป่วยไปห้องที่สภาพแสงต่างจากเดิมมาก
(๕) ...................... จอขึ้น SENS หรือ CHECK SENSOR ซ้ำ ๆ ทั้งที่จัดตำแหน่งแล้ว
(๖) ......................... ค่าอัตราการไหลบนจอไม่ตรงกับการนับด้วยตาเกินร้อยละ ๑๐


+==========================================================================+

๔.๗ การตรวจความถูกต้องหลังติดตั้ง
------------------------------------

  ไม่ว่าจะใช้เครื่องรุ่นใด หลังติดตั้งเสร็จให้ตรวจยืนยันด้วยวิธีเดียวกันนี้ทุกครั้ง
(๑) .......................... ตั้งนาฬิกาจับเวลา ๑ นาที แล้วนับหยดในกระเปาะด้วยตา
(๒) ............................... คำนวณอัตราการไหลจากสมการที่ ฉ.๓ ในภาคผนวก ฉ
                              Q  =  (R × ๖๐) ÷ F                         (ฉ.๓)
  Q  คือ อัตราการไหล หน่วยมิลลิลิตรต่อชั่วโมง
  R  คือ จำนวนหยดที่นับได้ใน ๑ นาที หน่วยหยดต่อนาที
  F  คือ ค่า Drop Factor จากซองชุดให้สารน้ำ หน่วยหยดต่อมิลลิลิตร
(๓) ...... เทียบกับตัวเลขที่แสดงบนหน้าจอ ต้องต่างกันไม่เกินร้อยละ ๑๐ ตามสมการที่ ฉ.๑๐
               | Q วัดได้ − Q ตามคำสั่ง |  ÷  Q ตามคำสั่ง  ≤  ๐.๑๐         (ฉ.๑๐)
(๔) ... ถ้าต่างมากกว่านั้น ให้ตรวจสองอย่างตามลำดับ คือ ค่า Drop Factor ในระบบตรงกับซองชุดให้สารน้ำหรือไม่ และตำแหน่งเซนเซอร์ถูกต้องตามหัวข้อ ๔.๒ หรือไม่
(๕) ..................................... บันทึกผลการตรวจไว้ในแบบฟอร์มภาคผนวก ก

๕.๑ ระดับความเร่งด่วนของสัญญาณเตือน
---------------------------------------

  ระบบแบ่งสัญญาณเตือนออกเป็นสองระดับ เพื่อให้พยาบาลจัดลำดับความสำคัญได้เมื่อมีหลาย

(๑) ... เหตุวิกฤต ได้แก่ ไหลเร็วเกิน ไหลช้าเกิน หยุดไหล ให้ครบตามแผนแล้ว และเซนเซอร์ไม่จับหยด จะมีเสียงเตือนต่อเนื่อง ไฟสีแดง และจอเครื่องข้างเตียงแสดงหน้าเตือนเต็มจอ ให้ไปตรวจที่เตียงทันที

๖.๒ กรณีเครื่องศูนย์กลางแสดง OFFLINE ทั้งที่เครื่องข้างเตียงทำงานปกติ
---------------------------------------------------------------------

  อาการนี้พบบ่อยเมื่อใช้งานพร้อมกันหลายเตียง ลักษณะเฉพาะคือ จอของเครื่องข้างเตียง
  แสดงว่า ONLINE และแสดงแผนการให้สารน้ำที่รับมาจากเครื่องศูนย์กลางได้ครบถ้วน แต่หน้าจอ
  เครื่องศูนย์กลางกลับแสดงว่าเตียงนั้น OFFLINE
  สาเหตุอยู่ที่วิธีที่ระบบแยกแยะเตียง กล่าวคือ เครื่องศูนย์กลางแยกเตียงจาก “เลขเตียง”
  ที่ส่งมาในข้อมูลเท่านั้น หากมีเครื่องสองเครื่องตั้งเลขเตียงซ้ำกัน ข้อมูลของทั้งสองเครื่อง
  จะถูกเขียนทับอยู่ในช่องเดียวกัน ทำให้เตียงที่เหลือไม่มีข้อมูลและแสดงเป็น OFFLINE
  ในขณะที่เครื่องทั้งสองยังรับข้อมูลจากเครื่องศูนย์กลางได้ตามปกติ จอของทั้งคู่จึงแสดงว่า
  ONLINE

  ๖.๒.๑ ขั้นตอนการตรวจสอบตามลำดับ
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

(๑) ... เปิดหน้าเว็บ แล้วดูแถบวินิจฉัยสีเข้มที่ด้านบนของหน้า หากขึ้นข้อความว่ามีเครื่องตั้งเลขเตียงซ้ำกัน ให้ข้ามไปทำข้อ (๔) ได้ทันที
(๒) ... ดูแถวรหัสเครื่อง (MAC) ในการ์ดของทุกเตียง ค่านี้ต้องไม่ซ้ำกันเลย หากเตียงใดมีเครื่องหมายเตือนกำกับอยู่ แสดงว่าเลขเตียงนั้นซ้ำ
(๓) ... ที่เครื่องศูนย์กลาง กดปุ่มเปลี่ยนหน้าไปจนถึงหน้าตรวจการเชื่อมต่อ (LINK DIAGNOSTIC) แล้วอ่านตารางตามหัวข้อ ๖.๓
(๔) ... เดินไปที่เครื่องข้างเตียงทุกเครื่องที่ใช้งานอยู่ กดปุ่ม ๓ ครั้งเพื่อเข้าหน้าตั้งเลขเตียง แล้วจดเลขที่แสดงไว้
(๕) ... แก้เลขเตียงที่ซ้ำกันให้เป็นเลขที่ยังไม่มีผู้ใช้ โดยกดทีละครั้งจนได้เลขที่ต้องการ ระบบบันทึกเองภายใน ๔ วินาที
(๖) ... ตรวจว่าเลขเตียงของทุกเครื่องอยู่ในช่วง ๑ ถึงจำนวนเตียงที่เปิดใช้บนเครื่องศูนย์กลาง หากมีเลขเกิน ให้กดเพิ่มจำนวนเตียงบนหน้าเว็บ หรือเปลี่ยนเลขที่เครื่องให้อยู่ในช่วง
(๗) ... กลับมาดูหน้าจอเครื่องศูนย์กลาง เตียงที่แก้แล้วจะกลับมาแสดงข้อมูลภายในไม่เกิน ๑๐ วินาที

๖.๓ การใช้หน้าตรวจการเชื่อมต่อ
--------------------------------

  ส่งข้อมูลมาในเลขนั้น และคุณภาพลิงก์ วิธีอ่านมีดังนี้
(๑) ... เครื่องหมายดอกจันต่อท้ายรหัสเครื่อง หมายความว่าเลขเตียงนั้นมีเครื่องมากกว่าหนึ่งเครื่องส่งข้อมูลมา ต้องแก้ไขทันที
(๒) ... แถวที่แสดงเป็นแถบกลับสี หมายความว่าได้ยินเลขเตียงนั้น แต่ยังไม่ได้เปิดใช้เตียงจำนวนมากพอ ให้กดเพิ่มจำนวนเตียงบนหน้าเว็บ
(๓) ... เครื่องหมายขีดสองขีด หมายความว่าไม่เคยได้ยินเลขเตียงนั้นเลยในหนึ่งนาทีที่ผ่านมา
(๔) ... ตัวเลขคุณภาพลิงก์ ค่าปกติคือร้อยละ ๙๐ ถึง ๑๐๐ หากต่ำกว่าร้อยละ ๖๐ ให้ดูตารางที่ ๑๗
(๕) ... ข้อความที่แถบล่างสุด สรุปผลการตรวจให้ในบรรทัดเดียว เช่น ALL BED IDs UNIQUE หมายความว่าเลขเตียงไม่ซ้ำกันเลย

  ตารางอัตราหยดสำเร็จรูป
  ตารางนี้คำนวณล่วงหน้าไว้จากสมการที่ ฉ.๒ และสมการที่ ฉ.๔ ในภาคผนวก ฉ หากอัตราการไหล
  ตามคำสั่งการรักษาไม่มีในตาราง ให้คำนวณเองจากสมการต่อไปนี้
                              R  =  (Q × F) ÷ ๖๐                         (ฉ.๒)
                                 T  =  V ÷ Q                             (ฉ.๔)
  R  คือ อัตราหยด หน่วยหยดต่อนาที
  Q  คือ อัตราการไหล หน่วยมิลลิลิตรต่อชั่วโมง
  F  คือ ค่า Drop Factor จากซองชุดให้สารน้ำ หน่วยหยดต่อมิลลิลิตร
  T  คือ เวลาจนสารน้ำหมดถุง หน่วยชั่วโมง  และ V คือ ปริมาตรในถุง หน่วยมิลลิลิตร

  คำถามที่พบบ่อย
  คำถามที่ 1  ระบบนี้ควบคุมอัตราการไหลให้เองได้หรือไม่
  คำตอบ  ไม่ได้ ระบบทำหน้าที่เฝ้าระวังและแจ้งเตือนเท่านั้น การปรับอัตราการไหลยังต้องทำ
  ที่โรลเลอร์ด้วยมือของพยาบาลเสมอ
  คำถามที่ 2  ถ้าระบบไม่แจ้งเตือน แปลว่าผู้ป่วยปลอดภัยหรือไม่
  คำตอบ  ไม่ได้แปลเช่นนั้น ระบบตรวจจับได้เฉพาะความผิดปกติของการไหลเท่านั้น ไม่สามารถ
  ตรวจจับสารน้ำรั่วซึมออกนอกหลอดเลือด หลอดเลือดดำอักเสบ หรือการติดเชื้อได้ การตรวจ
  เยี่ยมตามรอบยังต้องปฏิบัติตามเดิม
  คำถามที่ 3  ทำไมปรับโรลเลอร์แล้วตัวเลขบนจอยังไม่เปลี่ยนทันที
  คำตอบ  ระบบคำนวณอัตราการไหลจากหยดจริงในช่วงเวลาหนึ่ง จึงต้องใช้เวลาประมาณ ๒๐ ถึง
  ๓๐ วินาทีกว่าค่าจะนิ่งและสถานะจะกลับเป็น OK
  คำถามที่ 4  ผู้ป่วยเดินไปห้องน้ำแล้วถุงสารน้ำแกว่ง ระบบจะนับหยดผิดหรือไม่
  คำตอบ  ไม่ผิด ระบบออกแบบให้ตัดผลของการแกว่งออกโดยโครงสร้างของอัลกอริทึม หนึ่งหยด
  จะถูกนับเป็นหนึ่งครั้งเสมอ แต่หากถุงแกว่งจนสารน้ำไม่หยดตามปกติ ระบบอาจแจ้งเตือนว่าไหล
  ช้าได้
  คำถามที่ 5  ระบบจะเตือนซ้ำนานแค่ไหนถ้าไม่มีใครกดรับทราบ
  คำตอบ  เหตุวิกฤตจะเตือนต่อเนื่องจนกว่าจะแก้ไขสาเหตุ ส่วนการเตือนสารน้ำใกล้หมดจะเตือน
  ซ้ำทุก ๕ นาทีจนกว่าจะมีผู้กดรับทราบ
  คำถามที่ 6  กดพักเสียงเตือนแล้วต้องไปที่เตียงอีกหรือไม่
  คำตอบ  ต้องไปทุกครั้ง การพักเสียงเตือนเพียงทำให้เสียงเงียบไป ๒ นาทีเท่านั้น ไม่ได้
  แก้ไขสาเหตุและไม่ได้หยุดการเฝ้าระวัง
  คำถามที่ 7  เปลี่ยนถุงใหม่แล้วต้องทำอะไรเพิ่ม
  คำตอบ  ต้องกดปุ่มเริ่มถุงใหม่บนหน้าเว็บทุกครั้ง มิฉะนั้นปริมาตรสะสมจะนับต่อจากถุงเดิม
  ทำให้ระบบเตือนว่าให้ครบแล้วเร็วกว่าความเป็นจริง
  คำถามที่ 8  เครื่องข้างเตียงขึ้นว่า ONLINE แต่เครื่องศูนย์กลางขึ้นว่า OFFLINE เกิดจาก
  อะไร
  คำตอบ  ส่วนใหญ่เกิดจากมีเครื่องสองเครื่องตั้งเลขเตียงซ้ำกัน ให้ตรวจตามขั้นตอนในหัวข้อ
  ๖.๒
  คำถามที่ 9  ถ้าไฟดับ ข้อมูลที่บันทึกไว้จะหายหรือไม่
  คำตอบ  ข้อมูลบันทึกรายนาทีจะหายไป จึงควรดาวน์โหลดไฟล์ข้อมูลเมื่อสิ้นสุดการให้สารน้ำ
  หรือเมื่อสิ้นเวรทุกครั้ง ส่วนค่าตั้งของแต่ละเตียงจะถูกเก็บไว้และกลับมาเหมือนเดิมหลัง
  เปิดเครื่องใหม่
  คำถามที่ 10  ใช้กับผู้ป่วยที่ให้เลือดได้หรือไม่
  คำตอบ  ไม่ได้ คู่มือฉบับนี้และระบบนี้ไม่ครอบคลุมการให้เลือดและส่วนประกอบของเลือด
  คำถามที่ 11  ตั้งเลขเตียงได้สูงสุดเท่าไร
  คำตอบ  ตั้งได้ ๑ ถึง ๘ และเลขต้องอยู่ในช่วงไม่เกินจำนวนเตียงที่เปิดใช้บนเครื่อง
  ศูนย์กลาง
  คำถามที่ 12  หน้าจอเครื่องข้างเตียงดับไปเอง เครื่องเสียหรือไม่
  คำตอบ  ไม่เสีย เป็นโหมดประหยัดพลังงานที่ทำงานเมื่อไม่มีการกดปุ่มนานประมาณ ๓ นาที
  ระบบยังนับหยดและเฝ้าระวังตามปกติ กดปุ่ม ๑ ครั้งเพื่อปลุกจอ

  ภาคผนวก ฉ
==============================================================================

  สมการทั้งหมดที่ระบบใช้
  ภาคผนวกนี้รวบรวมสมการทุกสมการที่ระบบ Smart IV Alert ใช้ ทั้งสมการที่พยาบาลใช้คำนวณ
  ด้วยมือที่ข้างเตียง และสมการที่เครื่องใช้คำนวณภายใน เพื่อให้ผู้ใช้งานและผู้ตรวจสอบ สามารถ
  ตรวจทานค่าที่ระบบแสดงได้ทุกค่าด้วยตนเอง ทุกสมการในภาคผนวกนี้ตรงกับที่เขียนไว้ ใน
  เฟิร์มแวร์จริงทุกตัวแปร

ฉ.๒  สมการที่พยาบาลใช้ที่ข้างเตียง
------------------------------------


  ฉ.๒.๑  การแปลงอัตราการไหลเป็นอัตราหยด
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  การให้สารน้ำควบคุมด้วยโรลเลอร์แคลมป์ ซึ่งพยาบาลปรับโดยการนับหยดต่อนาที ไม่ใช่การ
  ตั้งค่า เป็นมิลลิลิตรต่อชั่วโมงโดยตรง จึงต้องแปลงหน่วยด้วยค่า Drop Factor การอนุมาน
  ทำได้สองขั้น
  ขั้นที่ ๑  แปลงปริมาตรต่อชั่วโมงเป็นจำนวนหยดต่อชั่วโมง โดยคูณด้วยจำนวนหยดต่อมิลลิลิตร
                          จำนวนหยดต่อชั่วโมง  =  Q × F                     (ฉ.๑)
  ตรวจหน่วย  (มิลลิลิตรต่อชั่วโมง) × (หยดต่อมิลลิลิตร)  =  หยดต่อชั่วโมง  หน่วย
  มิลลิลิตรตัดกันพอดี
  ขั้นที่ ๒  แปลงชั่วโมงเป็นนาที โดยหารด้วย ๖๐ เพราะหนึ่งชั่วโมงมี ๖๐ นาที
                              R  =  (Q × F) ÷ ๖๐                         (ฉ.๒)
  R  คือ อัตราหยดที่ต้องปรับโรลเลอร์ให้ได้ หน่วยหยดต่อนาที
  Q  คือ อัตราการไหลตามคำสั่งการรักษา หน่วยมิลลิลิตรต่อชั่วโมง
  F  คือ ค่า Drop Factor จากซองชุดให้สารน้ำ หน่วยหยดต่อมิลลิลิตร

+==========================================================================+
| ข้อสังเกตที่ช่วยให้ทำงานเร็วขึ้น                                              |
| ชุดหยดละเอียด F = ๖๐ จะได้ R เท่ากับ Q เสมอ เพราะ ๖๐ หารด้วย ๖๐ เท่ากับ ๑     |
| เช่น คำสั่ง ๔๕ มิลลิลิตรต่อชั่วโมง ใช้ชุด ๖๐ หยดต่อมิลลิลิตร ปรับให้ได้ ๔๕ หยดต่อ  |
| นาที ไม่ต้องคำนวณ                                                          |
+==========================================================================+


  ฉ.๒.๒  การคำนวณย้อนกลับ ใช้ตรวจสอบข้างเตียง
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  เมื่อนับหยดได้แล้วและต้องการทราบว่าเท่ากับอัตราการไหลกี่มิลลิลิตรต่อชั่วโมง ให้ย้ายข้าง
  สมการที่ ฉ.๒ จะได้
                              Q  =  (R × ๖๐) ÷ F                         (ฉ.๓)
  สมการนี้คือสมการที่ใช้ในหัวข้อ ๔.๗ การตรวจความถูกต้องหลังติดตั้ง และหัวข้อ ๗.๔ การ
  ตรวจสอบตามรอบเวลา โดยนำค่าที่คำนวณได้ไปเทียบกับตัวเลขบนหน้าจอเครื่องประจำเตียง

  ฉ.๒.๓  ระยะเวลาที่สารน้ำจะหมดถุง
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

                                 T  =  V ÷ Q                             (ฉ.๔)
  T  คือ ระยะเวลาจนสารน้ำหมดถุง หน่วยชั่วโมง
  V  คือ ปริมาตรสารน้ำในถุง หน่วยมิลลิลิตร
  Q  คือ อัตราการไหล หน่วยมิลลิลิตรต่อชั่วโมง
  ตัวอย่าง สารน้ำ ๑๐๐๐ มิลลิลิตร ให้ที่ ๑๒๕ มิลลิลิตรต่อชั่วโมง จะได้ T เท่ากับ ๑๐๐๐
  หารด้วย ๑๒๕ เท่ากับ ๘ ชั่วโมง

ฉ.๓  สมการที่เครื่องใช้คำนวณภายใน
------------------------------------

  หัวข้อนี้เป็นสมการที่เฟิร์มแวร์ใช้จริง ผู้ใช้งานทั่วไปไม่จำเป็นต้องคำนวณเอง แต่รวบรวมไว้
  เพื่อให้ผู้วิจัยตรวจสอบความถูกต้องของค่าที่ระบบรายงานได้

  ฉ.๓.๑  ปริมาตรสารน้ำสะสมที่ผู้ป่วยได้รับ
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  เครื่องประจำเตียงนับจำนวนหยดสะสม แล้วแปลงกลับเป็นปริมาตรด้วยค่า Drop Factor
                               V สะสม  =  N ÷ F                          (ฉ.๕)
  เครื่องศูนย์กลางคำนวณค่านี้ใหม่จากจำนวนหยดที่ได้รับ โดยใช้ค่า Drop Factor ที่ตั้งไว้ที่
  เครื่องศูนย์กลางเป็นหลัก จึงไม่มีความคลาดเคลื่อนสะสมจากการแปลงหน่วยสองต่อ

  ฉ.๓.๒  อัตราการไหลที่เครื่องประจำเตียงวัดได้
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  เครื่องบันทึกเวลาที่หยดตกล่าสุด ๘ หยด แล้วคำนวณอัตราการไหลจากจำนวนหยดที่ตกจริง หาร
  ด้วยเวลาที่ใช้ไปทั้งหน้าต่าง
                    Q  =  [ (n − ๑) ÷ F ] × ๓,๖๐๐,๐๐๐ ÷ Δt               (ฉ.๖)
  n   คือ จำนวนเวลาที่บันทึกไว้ในหน้าต่าง มากที่สุด ๘ ค่า
  Δt  คือ ผลต่างระหว่างเวลาที่บันทึกใหม่สุดกับเก่าสุด หน่วยมิลลิวินาที
  ๓,๖๐๐,๐๐๐  คือ จำนวนมิลลิวินาทีในหนึ่งชั่วโมง ใช้แปลงหน่วยเวลาให้เป็นต่อชั่วโมง
  เหตุที่ใช้ n ลบหนึ่ง เพราะเวลา n ค่าแบ่งช่วงเวลาออกเป็น n ลบหนึ่งช่วง จึงมีหยดตกจริง
  n ลบหนึ่งหยดในช่วงเวลา Δt นั้น สมการนี้จึงเป็นการนับหยดจริงต่อเวลาจริง ซึ่งเป็น
  วิธีเดียวกับที่พยาบาลนับหยดหนึ่งนาที ค่าที่อ่านจากหน้าจอจึงตรงกับค่าที่พยาบาลนับได้

  ฉ.๓.๓  อัตราการไหลที่บันทึกลงบันทึกรายนาที
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  เครื่องศูนย์กลางบันทึกข้อมูลทุกหนึ่งนาที โดยคำนวณอัตราการไหลจากจำนวนหยดที่นับได้จริง
  ในนาทีนั้น
                         Q  =  ( N ๑ นาที ÷ F ) × ๖๐                     (ฉ.๗)
  สมการที่ ฉ.๖ และ ฉ.๗ ให้ผลตรงกัน เพราะทั้งคู่คือการนับหยดจริงหารด้วยเวลาจริง
  ต่างกันเพียงความยาวของช่วงเวลาที่ใช้ ค่าที่แสดงบนหน้าจอกับค่าที่บันทึกไว้จึงไม่ขัดแย้ง
  กัน

  ฉ.๓.๔  คาบการหยดตามอัตราที่ตั้งไว้
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  ใช้กำหนดจังหวะภาพหยดน้ำบนหน้าจอ และใช้เป็นฐานในการตัดสินว่าสายพับหรือไม่
                       T หยด  =  ๓,๖๐๐,๐๐๐ ÷ ( Q × F )                   (ฉ.๘)
  เมื่อ T หยด คือ ระยะเวลาระหว่างหยดสองหยดที่ติดกัน หน่วยมิลลิวินาที ตัวส่วนคือ
  จำนวนหยดทั้งหมดในหนึ่งชั่วโมงตามสมการที่ ฉ.๑

  ฉ.๓.๕  เกณฑ์เวลาที่ใช้ตัดสินว่าสายพับ
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  ระบบถือว่าสายพับหรือหยุดไหล เมื่อไม่มีหยดใดตกเลยนานเกิน ๒.๕ เท่าของคาบการหยดตาม
  เป้าหมาย
                           T สายพับ  =  ๒.๕ × T หยด                      (ฉ.๙)
  โดยจำกัดค่าไว้ระหว่าง ๘ วินาที ถึง ๓๐๐ วินาที ค่าต่ำสุด ๘ วินาทีป้องกันการเตือน
  พร่ำเพรื่อ เมื่อตั้งอัตราไหลสูง ส่วนค่าสูงสุด ๓๐๐ วินาทีทำให้ยังตรวจจับได้แม้ตั้งอัตราไหล
  ต่ำมาก

ฉ.๔  สมการเกณฑ์การตัดสิน
------------------------------


  ฉ.๔.๑  เกณฑ์ยอมรับของการตรวจความถูกต้อง
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  ใช้ในหัวข้อ ๔.๗ และ ๗.๔ ถือว่าผ่านเมื่อค่าที่วัดได้ต่างจากคำสั่งการรักษาไม่เกินร้อยละ ๑๐
               | Q วัดได้ − Q ตามคำสั่ง |  ÷  Q ตามคำสั่ง  ≤  ๐.๑๐         (ฉ.๑๐)

  ฉ.๔.๒  เกณฑ์การแจ้งเตือนอัตราการไหลผิดปกติ
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  ระบบจะแจ้งเตือนเมื่อเข้าเงื่อนไขต่อไปนี้และเป็นเช่นนั้นต่อเนื่องนานเกิน ๒๐ วินาที การ
  กำหนดให้ต้องต่อเนื่องก่อนช่วยไม่ให้เสียงเตือนดังจากการแกว่งชั่วครู่ เช่น ผู้ป่วยขยับแขน
                เตือน FAST เมื่อ  Q จริง  >  ๑.๓๕ × Q ตามคำสั่ง           (ฉ.๑๑)
                เตือน SLOW เมื่อ  Q จริง  <  ๐.๖๕ × Q ตามคำสั่ง           (ฉ.๑๒)

+==========================================================================+
| ข้อควรระวังสำคัญ  เกณฑ์เตือนกับเกณฑ์ตรวจสอบไม่ใช่ค่าเดียวกัน                 |
| เกณฑ์แจ้งเตือนตามสมการที่ ฉ.๑๑ และ ฉ.๑๒ คือ บวกลบร้อยละ ๓๕                  |
| เกณฑ์ยอมรับของการตรวจความถูกต้องตามสมการที่ ฉ.๑๐ คือ บวกลบร้อยละ ๑๐          |
| สองค่านี้ต่างกันโดยเจตนา เพราะทำหน้าที่คนละอย่าง เกณฑ์เตือนกว้างกว่าเพื่อไม่ให้     |
| เสียงดังพร่ำเพรื่อจนพยาบาลเลิกสนใจ ส่วนเกณฑ์ตรวจสอบแคบกว่าเพื่อคุมคุณภาพ        |
| ดังนั้น การที่ระบบไม่แจ้งเตือน ไม่ได้แปลว่าอัตราการไหลอยู่ในเกณฑ์บวกลบร้อยละ ๑๐    |
| พยาบาลจึงต้องตรวจสอบตามรอบเวลาในหัวข้อ ๗.๔ เสมอ แม้ไม่มีเสียงเตือนใด ๆ       |
| เกิดขึ้นเลยตลอดเวร                                                        |
+==========================================================================+


  ฉ.๔.๓  เกณฑ์แจ้งเตือนสารน้ำใกล้หมด
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

                 เตือน NEAR END เมื่อ  V สะสม  ≥  p × V ตามแผน           (ฉ.๑๓)
  เมื่อ p คือ สัดส่วนที่ตั้งไว้ในระบบ ตั้งได้ระหว่างร้อยละ ๕๐ ถึงร้อยละ ๙๕ ค่าปริยายคือ
  ร้อยละ ๘๐

  ฉ.๔.๔  ความคลาดเคลื่อนของปริมาตรที่ผู้ป่วยได้รับจริง
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  ใช้ในการเก็บข้อมูลวิจัย เป็นค่าที่ระบบคำนวณให้เมื่อสารน้ำถุงนั้นให้ครบแล้ว
               ความคลาดเคลื่อน (มิลลิลิตร)  =  V จริง − V ตามแผน         (ฉ.๑๔)
    ความคลาดเคลื่อน (ร้อยละ)  =  [ ( V จริง − V ตามแผน ) ÷ V ตามแผน ] × ๑๐๐ (ฉ.๑๕)
  ค่าที่เป็นบวกหมายถึงผู้ป่วยได้รับสารน้ำมากกว่าแผน ค่าที่เป็นลบหมายถึงได้รับน้อยกว่าแผน

ฉ.๕  ตัวอย่างการคำนวณทีละขั้น
---------------------------------


  ตัวอย่างที่ ๑  คำสั่ง ๑๐๐ มิลลิลิตรต่อชั่วโมง ชุดให้สารน้ำ ๒๐ หยดต่อมิลลิลิตร
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

  โจทย์  ต้องปรับโรลเลอร์ให้ได้กี่หยดต่อนาที และสารน้ำ ๑๐๐๐ มิลลิลิตรจะหมดในกี่ชั่วโมง
  ขั้นที่ ๑  ใช้สมการที่ ฉ.๑  จำนวนหยดต่อชั่วโมง = ๑๐๐ × ๒๐ = ๒,๐๐๐ หยดต่อชั่วโมง
  ขั้นที่ ๒  ใช้สมการที่ ฉ.๒  R = ๒,๐๐๐ ÷ ๖๐ = ๓๓.๓ ปัดเป็น ๓๓ หยดต่อนาที
  ขั้นที่ ๓  ใช้สมการที่ ฉ.๔  T = ๑๐๐๐ ÷ ๑๐๐ = ๑๐ ชั่วโมง
