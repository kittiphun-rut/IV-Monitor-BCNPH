# ผังการเชื่อมต่ออุปกรณ์ (KiCad)

ผังในโฟลเดอร์นี้สร้างด้วย `tools/kicad-gen/gen_schematics.py` ซึ่ง **อ่านหมายเลขขา
GPIO จากไฟล์เฟิร์มแวร์โดยตรง ไม่ได้กรอกด้วยมือ** ถ้าย้ายขาในเฟิร์มแวร์แล้วรันสคริปต์ใหม่
ผังจะตามไปเองทันที ผังกับโค้ดจึงไม่มีทางหลุดจากกัน

```bash
python3 tools/kicad-gen/gen_schematics.py
```

| ไฟล์ | บอร์ด | อ่านขาจาก |
|---|---|---|
| `Station-BedNode.kicad_sch` | เครื่องประจำเตียง v7.7.3 | `firmware/ESP32-S3-Station-V_7_7_3/` |
| `Host-OLED.kicad_sch` | เครื่องศูนย์กลาง v4.7.5-OLED | `firmware/ESP32-S3-Host-OLED-V_4_7_5/` |

เปิดด้วย KiCad 7 ขึ้นไป (ไฟล์ `.kicad_pro` มีให้แล้ว) นิยามสัญลักษณ์ทั้งหมดฝังอยู่ในไฟล์
จึงเปิดได้บนเครื่องที่ไม่ได้ติดตั้งไลบรารีมาตรฐานของ KiCad

## ทำไมข้อความในผังเป็นภาษาอังกฤษ

KiCad 7 **ไม่รองรับการจัดวางสระและวรรณยุกต์ไทย** ทดสอบแล้วพบว่าเครื่องหมายบนและล่าง
หายทั้งหมด เช่น "อัตราการไหล" เรนเดอร์ออกมาเป็น "อตราการไหล" และ "ผู้ป่วย" เป็น "ผปวย"
ถ้าใส่ภาษาไทยลงไปจะได้เอกสารที่อ่านผิดความหมาย จึงใช้ภาษาอังกฤษในผัง (เป็นธรรมเนียม
ของงาน EDA อยู่แล้ว) และอธิบายภาษาไทยไว้ในไฟล์นี้แทน

## เครื่องประจำเตียง (Station v7.7.3)

| อุปกรณ์ | ขา ESP32-S3 | หมายเหตุ |
|---|---|---|
| จอ TFT ST7789 1.47" — SCLK | GPIO 13 | |
| จอ TFT — MOSI (SDA) | GPIO 12 | |
| จอ TFT — RST | GPIO 11 | |
| จอ TFT — DC | GPIO 10 | |
| จอ TFT — CS | GPIO 9 | |
| จอ TFT — BLK (ไฟหน้าจอ) | GPIO 8 | |
| เซนเซอร์ TCRT5000 — AO | GPIO 4 | ขา DO ไม่ได้ใช้ |
| บัซเซอร์ | GPIO 3 | ชนิด Passive ขับด้วย `tone()` |
| ปุ่มผู้ใช้ | GPIO 2 | ต่อลง GND ได้เลย |
| RGB LED (WS2812) | GPIO 48 | **อยู่บนบอร์ดแล้ว ไม่ต้องต่อเพิ่ม** |

**ข้อควรระวัง**

1. จ่ายไฟจอและเซนเซอร์ด้วย **3V3 เท่านั้น** ขา GPIO ของ ESP32-S3 ทนได้ 3.3V การต่อ 5V
   เข้าขาสัญญาณจะทำให้ชิปเสียหาย
2. ปุ่มใช้ `pinMode(INPUT_PULLUP)` จึงต่อระหว่าง GPIO กับ GND ได้เลย ไม่ต้องมีตัวต้านทาน
   พูลอัปภายนอก
3. บัซเซอร์ที่ใช้ต้องเป็นชนิด **Passive** เพราะเฟิร์มแวร์สร้างความถี่เองด้วย `tone()`
   ถ้าใช้บัซเซอร์แบบแม่เหล็กซึ่งกินกระแสสูง ให้เพิ่มทรานซิสเตอร์ NPN ขับ อย่าต่อตรงกับ GPIO
4. วงจรวัดแบตเตอรี่ฝั่ง Station **ปิดอยู่ในเฟิร์มแวร์** (`STATION_BAT_ADC_PIN = -1`)
   ผังจึงไม่ได้วาดไว้ ถ้าจะเปิดใช้ ต้องแก้ค่านี้เป็นหมายเลขขา ADC แล้วต่อตัวแบ่งแรงดัน 1:1

## เครื่องศูนย์กลาง (Host v4.7.5-OLED)

| อุปกรณ์ | ขา ESP32-S3 | หมายเหตุ |
|---|---|---|
| จอ OLED SH1106 — SDA | GPIO 8 | I2C 400 kHz |
| จอ OLED SH1106 — SCL | GPIO 9 | |
| ปุ่มเปิด-ปิด / พักเสียงเตือน | GPIO 4 | **ต้องเป็น RTC GPIO (0-21)** |
| ปุ่มเปลี่ยนหน้าจอ | GPIO 5 | |
| บัซเซอร์ | GPIO 7 | ชนิด Passive |
| วัดแรงดันแบตเตอรี่ | GPIO 1 | ผ่านตัวแบ่งแรงดัน 1:1 |

**ข้อควรระวัง**

1. ปุ่มเปิด-ปิดต้องอยู่บนขา RTC GPIO เพราะใช้ปลุกเครื่องจาก deep sleep ด้วย `ext0`
   ที่ระดับลอจิก 0 ถ้าย้ายไปขาอื่นที่ไม่ใช่ RTC GPIO เครื่องจะปลุกไม่ขึ้น
2. **R1 กับ R2 ต้องมีค่าเท่ากัน** เฟิร์มแวร์คำนวณ `(raw / 4095) × 3.3 × 2.0`
   ซึ่งตรึงอัตราส่วนไว้ที่ 1:1 แล้ว ถ้าใช้ค่าต่างกันค่าที่อ่านได้จะผิด
   แบตเตอรี่เต็มที่ 4.2V ผ่านตัวแบ่งเหลือ 2.1V ยังอยู่ในช่วงที่ ADC รับได้
3. โมดูล OLED สำเร็จรูปส่วนใหญ่มีตัวต้านทานพูลอัป I2C มาแล้ว ถ้าโมดูลที่ใช้ไม่มี
   ให้เพิ่ม 4.7kΩ จาก SDA ขึ้น 3V3 และ 4.7kΩ จาก SCL ขึ้น 3V3
4. บัสวิ่งที่ 400 kHz ตามสเปก SH1106 ควรให้สายสั้นที่สุดเท่าที่ทำได้

## การตรวจสอบ

ผังทั้งสองผ่านการตรวจด้วย `kicad-cli` เวอร์ชัน 7.0.11 โดยตรวจสองชั้น

1. **เปิดไฟล์ได้จริง** — `kicad-cli sch export pdf` สร้าง PDF สำเร็จทั้งสองไฟล์
2. **การเชื่อมต่อถูกต้อง** — `kicad-cli sch export netlist` แล้วตรวจทุกเน็ตทีละเส้น
   ว่าตรงกับ `#define` ในเฟิร์มแวร์

```bash
kicad-cli sch export pdf     --output Station-BedNode.pdf Station-BedNode.kicad_sch
kicad-cli sch export netlist --output Station-BedNode.net Station-BedNode.kicad_sch
```

## ขอบเขตที่ยังไม่ได้ทำ

* **ยังไม่มีการวางลายวงจร (PCB layout)** ผังนี้เป็นผังการเชื่อมต่ออุปกรณ์ สำหรับต่อสาย
  ระหว่างโมดูลสำเร็จรูปหรือบัดกรีบนเพอร์ฟบอร์ด ยังไม่ได้ออกแบบแผ่นวงจรพิมพ์
* **ยังไม่ได้ประกอบและทดสอบกับฮาร์ดแวร์จริง** ผังสร้างจากการอ่านโค้ด ควรตรวจทานกับ
  ซิลค์สกรีนบนบอร์ดจริงอีกครั้งก่อนบัดกรี
* **ยังไม่มีผังของ Host รุ่นจอ TFT (v4.8.0) และรุ่นจอสัมผัส (v4.9.0)** ทั้งสองรุ่นใช้ผังขา
  ต่างจากรุ่น OLED
