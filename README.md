# IV-Monitor-CNB

ซอฟต์แวร์ของโครงการนวัตกรรม **Smart IV Alert** — ระบบตรวจวัดและแจ้งเตือนการให้สารน้ำทางหลอดเลือดดำ
(หอผู้ป่วยอายุรกรรม โรงพยาบาลสูงเม่น จังหวัดแพร่ / วิทยาลัยพยาบาลบรมราชชนนี แพร่)

## โครงสร้างที่เก็บ

เฟิร์มแวร์เก็บเป็น **โฟลเดอร์ชื่อคงที่สายละหนึ่ง** เลขเวอร์ชันอยู่ใน `#define APP_VERSION`
เวอร์ชันเก่าทุกตัวดูได้จาก [`VERSIONS.md`](VERSIONS.md) ซึ่งมีลิงก์โหลด zip ของทุกรุ่น

| ที่อยู่ | คำอธิบาย |
|---|---|
| `firmware/Station/` | **เฟิร์มแวร์เครื่องประจำเตียง สายหลัก** — ไม่ต้องคาลิเบรตด้วยมือ หนีบเซนเซอร์แล้วเปิดโรลเลอร์ เครื่องเรียนรู้เอง หมุนจอ 180 องศาได้ สุ่มจังหวะส่งข้อมูลกันชนกัน |
| `firmware/Station-Stable/` | **เฟิร์มแวร์เครื่องประจำเตียง สายเสถียร** — อัลกอริทึมตรวจจับเดิมพร้อมหน้าคาลิเบรต ๓ ขั้นแบบทำเอง สำหรับเครื่องที่ยังใช้วิธีเดิม |
| `firmware/Host-OLED/` | **เฟิร์มแวร์เครื่องส่วนกลาง จอ OLED** — ตรวจเลขเตียงซ้ำ หน้า LINK DIAGNOSTIC แอนิเมชันหยด หน้าเว็บ Dashboard |
| `firmware/Host-TFT28/` | **เฟิร์มแวร์เครื่องส่วนกลาง จอสี TFT 2.8"** — หน้าจอแนวทาง FOCUS + จอเตือนเต็มจอ |
| `firmware/Host-Touch24/` | **เฟิร์มแวร์เครื่องส่วนกลาง จอสัมผัส 2.4"** — ตั้งค่าได้บนจอ นาฬิกา DS3231 บันทึกลงการ์ด SD พร้อมคุณสมบัติครบเท่ารุ่นจอ OLED |
| `firmware/FlowSim-Lab/` | **เฟิร์มแวร์แบบจำลองกราฟการไหล + ทดสอบเซนเซอร์** (ไม่เชื่อมต่อ Host) — ใช้ทดลอง สาธิต และออกแบบหน้าจอ |
| `firmware/reference/` | เฟิร์มแวร์ตัวจริงที่ใช้อ้างอิง: Station v7.3.0 / v7.4.0 และ Host v4.6.0 |
| `tools/check-ino-types.py` | ตรวจว่า enum/struct ถูกประกาศก่อนจุดที่ Arduino แทรก prototype (กัน error `does not name a type`) |
| `tools/screen-preview/` | เครื่องมือเรนเดอร์ภาพหน้าจอ TFT จากไฟล์ .ino บนเครื่อง PC |
| `tools/touch-preview/` | เรนเดอร์ภาพหน้าจอของเฟิร์มแวร์ Host จอสัมผัส v4.9.0 บน PC |
| `tools/host-preview/` | เรนเดอร์ภาพหน้าจอ TFT ของเฟิร์มแวร์ Host v4.8.0-TFT บน PC |
| `tools/protocol-test/` | **ตรวจว่าโครงสร้างแพ็กเก็ต ESP-NOW ของทุกเฟิร์มแวร์ตรงกัน** (Host กับ Station ต้องตรงกันทุกไบต์) |
| `tools/oled-check/` | ตรวจว่าเฟิร์มแวร์ Host จอ OLED คอมไพล์ผ่านบน PC |
| `tools/oled-preview/` | **จำลองหน้าจอ OLED 128x64 ของ Host v4.7.4 บน PC** เรนเดอร์ออกมาเป็นภาพทุกหน้า รวมเฟรมแอนิเมชันหยด |
| `tools/host-rx-test/` | **ป้อนแพ็กเก็ตเสมือนเข้าฟังก์ชันรับของ Host บน PC** ตรวจว่า Host มองเห็นครบทุกเตียงจริงหรือไม่ (7 สถานการณ์ รวมกรณีเลขเตียงซ้ำ) |
| `tools/link-sim/` | **จำลองจังหวะเวลาของ ESP-NOW ทั้งระบบ** วัดว่าของเดิมทำให้ Host ขึ้น OFFLINE ผิดพลาดนานเท่าใด และของใหม่แก้ได้แค่ไหน |
| `tools/dashboard-preview/` | **เปิดหน้าเว็บ Dashboard บน PC พร้อมข้อมูลจำลอง** แล้วถ่ายภาพหน้าจอด้วย Chromium |
| `tools/detector-test/` | **ทดสอบอัลกอริทึมตรวจจับหยดบน PC** 10 สถานการณ์ (ถุงแกว่ง ระดับไหล สัญญาณรบกวนแรง ฯลฯ) ไม่ต้องมีบอร์ด |
| `tools/station-preview/` | เรนเดอร์ภาพทุกหน้าจอของเฟิร์มแวร์ Station v7.7.2 บน PC (มีเซนเซอร์จำลองในตัว) |
| `tools/ui-mockup/` | แบบร่าง UI ของจอ Station 3 แนวทาง (เรนเดอร์เป็นภาพเพื่อเลือกแบบก่อนลงมือเขียนจริง) |
| `hardware/` | **ผังการเชื่อมต่ออุปกรณ์ KiCad 7** ของเครื่องประจำเตียงและเครื่องศูนย์กลาง สร้างจากหมายเลขขาในเฟิร์มแวร์โดยอัตโนมัติ พร้อมสคริปต์ตรวจว่าผังตรงกับโค้ด |
| `docs/screens/` | ภาพตัวอย่างหน้าจอที่สร้างจากเครื่องมือข้างต้น |
| `docs/ui-concepts/` | ภาพเปรียบเทียบแบบร่าง UI ทั้ง 3 แนวทาง |
| `docs/screens-touch/` | ภาพหน้าจอจริงของ Host v4.9.1-TOUCH ทุกหน้า |
| `docs/ui-concepts-touch/` | แบบร่าง UI แบบสมาร์ตโฟนที่ใช้ประกอบการเลือก |
| `docs/screens-host/` | ภาพหน้าจอจริงของ Host v4.8.0-TFT ทุกหน้า |
| `docs/ui-concepts-host/` | ภาพเปรียบเทียบแบบร่าง UI ของ Host ทั้ง 3 แนวทาง |
| `docs/screens-dashboard/` | ภาพหน้าเว็บ Dashboard ที่เรนเดอร์จากเบราว์เซอร์จริง |
| `docs/screens-station/` | ภาพหน้าจอจริงของ Station v7.7.2 ทุกหน้า + ภาพเปรียบเทียบจอหมุน 180 องศา |
| `docs/คู่มือพยาบาล_Smart_IV_Alert.docx` | **คู่มือการปฏิบัติงานสำหรับพยาบาลวิชาชีพ** ตามรูปแบบเอกสารราชการไทย ๔๘ หน้า (ปก คำนำ สารบัญ ๗ บท ภาคผนวก ๕ ภาค รวมบทการติดตั้งเซนเซอร์และการคาลิเบรต) — สารบัญเป็นฟิลด์ TOC ที่อัปเดตเองได้ใน Word |
| `docs/คู่มือหน้าเว็บ_Smart_IV_Alert.docx` | **คู่มือการปฏิบัติงานเฉพาะหน้าเว็บ** ๓๐ หน้า อธิบายทุกหน้า ทุกปุ่ม และทุกบรรทัดบนการ์ดเตียง พร้อมภาพถ่ายหน้าจอจริงทั้ง ๔ หน้า |
| `docs/คู่มือพยาบาล_Smart_IV_Alert.txt` | คู่มือฉบับข้อความล้วน สำหรับคัดลอกไปใช้ต่อหรืออ่านโดยไม่ต้องมี Word |
| `docs/คู่มือพยาบาล_Smart_IV_Alert_ตัวอย่าง.pdf` | ตัวอย่าง PDF ของคู่มือ (เรนเดอร์ด้วยฟอนต์แทน ไม่ใช่ TH SarabunPSK) |
| `tools/manual-build/` | **สคริปต์สร้างคู่มือ .docx** สร้างสารบัญเป็นฟิลด์ TOC จริงพร้อมเลขหน้าที่คำนวณไว้ล่วงหน้า |
| `docs/screens-oled/` | ภาพจำลองหน้าจอ OLED ของ Host v4.7.4-OLED ทุกหน้า + เฟรมแอนิเมชันหยด |
