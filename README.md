# IV-Monitor-CNB

ซอฟต์แวร์ของโครงการนวัตกรรม **Smart IV Alert** — ระบบตรวจวัดและแจ้งเตือนการให้สารน้ำทางหลอดเลือดดำ
(หอผู้ป่วยอายุรกรรม โรงพยาบาลสูงเม่น จังหวัดแพร่ / วิทยาลัยพยาบาลบรมราชชนนี แพร่)

## โครงสร้างที่เก็บ

| ที่อยู่ | คำอธิบาย |
|---|---|
| `firmware/ESP32-S3-Station-V_7_7_2/` | **เฟิร์มแวร์เครื่องประจำเตียงรุ่นล่าสุด** — เหมือน v7.7.1 และ **สุ่มจังหวะส่งข้อมูล** แก้อาการ Host ขึ้น OFFLINE เมื่อมีหลายเตียง |
| `firmware/ESP32-S3-Station-V_7_7_1/` | เหมือน v7.7.0 ทุกอย่าง และหมุนจอ 180 องศาได้ที่หน้าเครื่อง |
| `firmware/ESP32-S3-Station-V_7_7_0/` | ไม่ต้องคาลิเบรตด้วยมือ พยาบาลแค่หนีบเซนเซอร์แล้วเปิดโรลเลอร์ เครื่องเรียนรู้เองแล้วขึ้น READY |
| `firmware/ESP32-S3-Station-V_7_5_3/` | **สายเสถียรรุ่นล่าสุด** — เหมือน v7.5.2 (คาลิเบรต 3 ขั้นแบบทำเอง) และสุ่มจังหวะส่งข้อมูลเหมือน v7.7.2 |
| `firmware/ESP32-S3-Station-V_7_5_2/` | เหมือน v7.5.1 และหมุนจอ 180 องศาได้ที่หน้าเครื่อง |
| `firmware/ESP32-S3-Station-V_7_5_1/` | รุ่นก่อนหน้า — เซ็นเซอร์ IR อนาล็อก พร้อมหน้าคาลิเบรต 3 ขั้นแบบทำเอง |
| `firmware/ESP32-S3-Station-V_7_5_0/` | รุ่นก่อนหน้า — หน้าจอแนวทาง IV BAG, 4 หน้า, กราฟแนวโน้ม 30 นาที (ตรรกะตรวจจับหยดแบบเดิม) |
| `firmware/ESP32-S3-Station-V_7_6_0/` | รุ่นทดลองสำหรับเซ็นเซอร์หยดแบบเอาต์พุตดิจิทัล — นับด้วย interrupt, ผังขาใหม่ DO=5 / Buzzer=6 / ปุ่ม=7 |
| `firmware/ESP32-S3-Host-Touch-V_4_9_0/` | **เฟิร์มแวร์ Host จอสัมผัส 2.4" (v4.9.1)** — ใช้งานเหมือนสมาร์ตโฟน ตั้งค่าได้บนจอ + ปุ่ม multifunction 1 ปุ่ม + นาฬิกา DS3231 + บันทึกลงการ์ด SD |
| `firmware/ESP32-S3-Host-TFT-V_4_8_0/` | **เฟิร์มแวร์ Host จอสี TFT 2.8"** — หน้าจอแนวทาง FOCUS + จอเตือนเต็มจอ (ต่อยอดจาก v4.7.0) |
| `firmware/ESP32-S3-Host-OLED-V_4_7_4/` | **เฟิร์มแวร์ศูนย์กลางจอ OLED รุ่นล่าสุด** — ตรวจจับ "สองเครื่องตั้งเลขเตียงซ้ำกัน" ซึ่งทำให้เตียงอื่นขึ้น OFFLINE, หน้า LINK DIAGNOSTIC, และจอที่อ่านง่ายขึ้นมาก |
| `firmware/ESP32-S3-Host-OLED-V_4_7_3/` | แก้จังหวะส่ง Sync ที่ชนกัน, วัดคุณภาพลิงก์, แอนิเมชันหยดน้ำเกลือ |
| `firmware/ESP32-S3-Host-OLED-V_4_7_2/` | ปรับหน้าเว็บ Dashboard: กรอบเขียวเมื่อปกติ, บอกปริมาณคงเหลือ, แถบแจ้งสถานะรวม, เสียงเตือนชัดขึ้น |
| `firmware/ESP32-S3-Host-OLED-V_4_7_1/` | รุ่นก่อนหน้า — ใช้กับ Station v7.4.x/v7.5.x/v7.7.x ได้ทุกรุ่น เพิ่มการเตือน "เซนเซอร์ยังไม่จับหยด" |
| `firmware/ESP32-S3-Host-V_4_7_0/` | รุ่นก่อนหน้าของ Host จอ OLED — ตัดระบบจัดการ Wi-Fi ออก ทำงานเป็น Access Point อย่างเดียว |
| `firmware/ESP32-S3-FlowSim-Lab/` | **เฟิร์มแวร์แบบจำลองกราฟการไหล + ทดสอบเซนเซอร์** (ไม่เชื่อมต่อ Host) — ใช้ทดลอง สาธิต และออกแบบหน้าจอ |
| `firmware/reference/` | เฟิร์มแวร์ตัวจริงที่ใช้อ้างอิง: Station v7.3.0 / v7.4.0 และ Host v4.6.0 |
| `tools/check-ino-types.py` | ตรวจว่า enum/struct ถูกประกาศก่อนจุดที่ Arduino แทรก prototype (กัน error `does not name a type`) |
| `tools/screen-preview/` | เครื่องมือเรนเดอร์ภาพหน้าจอ TFT จากไฟล์ .ino บนเครื่อง PC |
| `tools/touch-preview/` | เรนเดอร์ภาพหน้าจอของเฟิร์มแวร์ Host จอสัมผัส v4.9.0 บน PC |
| `tools/host-preview/` | เรนเดอร์ภาพหน้าจอ TFT ของเฟิร์มแวร์ Host v4.8.0-TFT บน PC |
| `tools/protocol-test/` | **ตรวจว่าโครงสร้างแพ็กเก็ต ESP-NOW ของทุกเฟิร์มแวร์ตรงกัน** (Host กับ Station ต้องตรงกันทุกไบต์) |
| `tools/oled-check/` | ตรวจว่าเฟิร์มแวร์ Host จอ OLED คอมไพล์ผ่านบน PC |
| `tools/oled-preview/` | **จำลองหน้าจอ OLED 128x64 ของ Host v4.7.4 บน PC** เรนเดอร์ออกมาเป็นภาพทุกหน้า รวมเฟรมแอนิเมชันหยด |
| `tools/host-rx-test/` | **ป้อนแพ็กเก็ตเสมือนเข้าฟังก์ชันรับของ Host บน PC** ตรวจว่า Host มองเห็นครบทุกเตียงจริงหรือไม่ (7 สถานการณ์ รวมกรณีเลขเตียงซ้ำ) |
| `tools/link-sim/` | **จำลองจังหวะเวลาของ ESP-NOW ทั้งระบบ** วัดว่าของเดิมทำให้ Host ขึ้น OFFLINE ผิดพลาดนานเท่าใด และของใหม่แก้ได้แค่ไหน |
| `tools/dashboard-preview/` | **เปิดหน้าเว็บ Dashboard บน PC พร้อมข้อมูลจำลอง** แล้วถ่ายภาพหน้าจอด้วย Chromium |

| `tools/station-preview/` | เรนเดอร์ภาพทุกหน้าจอของเฟิร์มแวร์ Station v7.7.2 บน PC (มีเซนเซอร์จำลองในตัว) |
