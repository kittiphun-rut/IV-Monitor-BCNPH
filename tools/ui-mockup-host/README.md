# UI Mockup (Host) — แบบร่างหน้าจอ TFT 2.8" ของเครื่อง Host

จอเป้าหมาย: **ST7789V 240x320 SPI 14 ขา (ไม่มีทัช)** หมุนใช้งานได้ทั้งแนวนอน (320x240) และแนวตั้ง (240x320)

```bash
./run.sh                       # ผลลัพธ์ไปที่ docs/ui-concepts-host/
```

| แบบ | การจัดหน้าจอ | จุดเด่น |
|---|---|---|
| **A BED GRID** | แนวนอน 320x240 — การ์ดเตียง 8 ช่อง | เห็นทุกเตียงพร้อมกันในหน้าเดียว ไม่ต้องกดเปลี่ยนหน้า |
| **B FOCUS** | แนวนอน 320x240 — เตียงที่ต้องดูตัวใหญ่ครึ่งจอ + รายการเตียงอื่น | เตียงที่มีเหตุเด่นชัดที่สุด เห็นค่าละเอียดโดยไม่ต้องกดเข้าไปดู |
| **C BIG LIST** | แนวตั้ง 240x320 — รายการเตียงเรียงลงมา 5 แถว | ตัวหนังสือใหญ่ที่สุด อ่านง่ายจากระยะไกล มีชื่อผู้ป่วยทุกแถว |

ทั้งสามแบบใช้ชุดสีเดียวกับเครื่องประจำเตียง (เขียว = ปกติ, เหลือง = ช้า, ส้ม = เร็ว/ใกล้หมดถุง,
แดง = ไม่มีการไหล, ฟ้า = พักการนับ, เทา = ออฟไลน์) และมีแถบสรุปเหตุการณ์ที่ขอบล่างเสมอ
