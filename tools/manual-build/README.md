# เครื่องมือสร้างคู่มือพยาบาล

สร้างไฟล์ `docs/คู่มือพยาบาล_Smart_IV_Alert.docx` ตามรูปแบบเอกสารราชการไทย

```bash
tools/manual-build/run.sh
```

## รูปแบบที่ใช้

| รายการ | ค่าที่ตั้ง |
|---|---|
| ขนาดกระดาษ | A4 |
| ขอบกระดาษ | บน ๑.๕ นิ้ว · ซ้าย ๑.๕ นิ้ว · ขวา ๑ นิ้ว · ล่าง ๑ นิ้ว |
| แบบอักษร | TH SarabunPSK ขนาด ๑๖ พอยต์ (หัวข้อ ๑๘-๒๐ พอยต์ ตัวหนา) |
| เลขหน้า | มุมบนขวา — ส่วนนำใช้พยัญชนะไทย (ก ข ค ง) เนื้อหาใช้เลขอารบิกเริ่มที่ ๑ |
| โครงเล่ม | ปก · คำนำ · สารบัญ · สารบัญตาราง · สารบัญภาพ · บทที่ ๑-๖ · ภาคผนวก ก-จ · เอกสารอ้างอิง |

## ทำไมต้องสร้างสองรอบ

สารบัญเป็นแบบพิมพ์เลขหน้าเอง (ไม่ใช่ฟิลด์ของ Word) เพื่อให้พิมพ์ออกมาถูกต้องทันที
โดยไม่ต้องให้ผู้ใช้กด update field ก่อน สคริปต์จึงทำสองรอบ

1. สร้างเล่มด้วยเลขหน้าเดิมใน `pagemap.json` แล้วแปลงเป็น PDF
2. `resolve_pages.py` อ่าน PDF หาว่าหัวข้อแต่ละหัวข้ออยู่หน้าใดจริง เขียนทับ `pagemap.json`
3. สร้างเล่มใหม่โดยเติมเลขหน้าที่ได้ลงในสารบัญ

เมื่อรันซ้ำจนเลขหน้าไม่เปลี่ยนอีก แปลว่าสารบัญตรงกับเล่มแล้ว

## ข้อควรทราบเรื่องแบบอักษร

เครื่องที่ใช้สร้างเอกสารนี้**ไม่มี TH SarabunPSK ติดตั้งอยู่** ตัวเอกสารระบุชื่อฟอนต์ไว้ถูกต้องแล้ว
และจะแสดงผลถูกต้องบนเครื่องที่มีฟอนต์นี้ (เครื่องราชการไทยทั่วไปมีอยู่แล้ว)
แต่ PDF ตัวอย่างและเลขหน้าใน `pagemap.json` คำนวณจากการเรนเดอร์ด้วยฟอนต์แทน (Loma)
ซึ่ง **กว้างกว่า** TH SarabunPSK เล็กน้อย

ดังนั้นเมื่อเปิดด้วย Word บนเครื่องที่มี TH SarabunPSK จริง ควร

1. ตรวจว่าเลขหน้าในสารบัญตรงกับเล่ม หากคลาดเคลื่อน ให้แก้ตัวเลขในสารบัญโดยตรง
2. หรือรัน `run.sh` ใหม่บนเครื่องที่ติดตั้ง TH SarabunPSK แล้ว เลขหน้าจะถูกคำนวณใหม่ให้เอง

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `manual_lib.js` | ตัวช่วยจัดรูปแบบ (ย่อหน้า หัวข้อ ตาราง ภาพ กล่องคำเตือน บรรทัดสารบัญ) |
| `part_front.js` | ปก คำนำ สารบัญ สารบัญตาราง สารบัญภาพ |
| `part_ch12.js` | บทที่ ๑ บทนำ และบทที่ ๒ ความรู้ทั่วไปเกี่ยวกับระบบ |
| `part_ch34.js` | บทที่ ๓ ขั้นตอนการปฏิบัติงาน และบทที่ ๔ สัญญาณเตือน |
| `part_ch56.js` | บทที่ ๕ การแก้ไขปัญหา และบทที่ ๖ การบำรุงรักษา |
| `part_appendix.js` | ภาคผนวก ก-จ และเอกสารอ้างอิง |
| `build_manual.js` | ประกอบทุกส่วนเป็นไฟล์ .docx |
| `resolve_pages.py` | อ่านเลขหน้าจริงจาก PDF |
| `make_images.py` | เตรียมภาพประกอบจากภาพหน้าจอที่เครื่องมือ preview สร้างไว้ |
| `manual-img/` | ภาพประกอบที่ใช้ในเล่ม |

## เมื่อแก้เนื้อหาคู่มือ

แก้ในไฟล์ `part_*.js` แล้วรัน `run.sh` ใหม่ เลขหน้าในสารบัญจะถูกปรับให้เองโดยอัตโนมัติ
