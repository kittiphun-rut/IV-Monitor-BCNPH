# UI Mockup — แบบร่างหน้าจอ Station 3 แนวทาง

ไฟล์ `station_ui_concepts.cpp` วาดหน้าจอด้วยคำสั่ง Adafruit GFX ชุดเดียวกับเฟิร์มแวร์จริง
แต่คอมไพล์และเรนเดอร์บนเครื่อง PC จึงเปรียบเทียบแบบต่าง ๆ ได้เร็วก่อนลงมือแก้เฟิร์มแวร์

```bash
./run.sh                    # ผลลัพธ์ไปที่ docs/ui-concepts/
```

| แบบ | แนวคิด | เหมาะกับ |
|---|---|---|
| **A — BIG NUMBER** | อัตราไหลตัวใหญ่เต็มจอ + เกจเทียบเป้าหมาย + เวลาที่เหลือ | อ่านค่าจากปลายเตียง/ระยะไกล |
| **B — STATUS CARD** | การ์ดสถานะสี + ไอคอนใหญ่ แล้วตามด้วยตัวเลข 4 ช่อง | ดู "ปกติ/ผิดปกติ" ให้รู้ทันทีโดยไม่ต้องอ่านตัวเลข |
| **C — IV BAG** | ภาพถุงน้ำเกลือที่ระดับน้ำลดลงจริง + กระเปาะหยด + ตัวเลขด้านข้าง | สื่อสารกับผู้ป่วย/ญาติ และดูปริมาณคงเหลือแบบรูปธรรม |

ทั้งสามแบบใช้ข้อความบนจอน้อยที่สุดเท่าที่จำเป็น (ไม่เกิน 10 ชิ้นต่อหน้า) ใช้สีและตำแหน่งแทนคำอธิบาย
และใช้แถบสถานะสีเดียวกันที่ขอบบนเพื่อบอกภาวะของเตียงตั้งแต่แรกเห็น
